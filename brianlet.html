    How it helps

    Practice that builds speed and accuracy

    Unlimited question papers

    Every click gives a new set of numbers, so a learner can repeat a level until it feels easy without meeting the same sums twice.

    Answer key on demand

    Keep the key hidden while the learner works, then turn it on to check each answer. The key always matches the sheet on screen.

    Built-in timer

    Start the timer before the first question and stop it at the last. Note the time on the sheet and try to beat it next round.
